# MELD Emotion Classification Recipe

Emotion classification on the [MELD](https://affective-meld.github.io/) dataset, using a frozen [WavLM Base+](https://github.com/microsoft/unilm/tree/master/wavlm) frontend (via [S3PRL](https://github.com/s3prl/s3prl)), a Transformer encoder and a linear head.

This configuration is a first working implementation, not a tuned one.

## Dataset

MELD is a multimodal dataset of multi-party conversations from the TV series *Friends*, annotated with 7 emotions (`neutral`, `joy`, `surprise`, `anger`, `sadness`, `disgust`, `fear`). This recipe uses the audio track for single-label classification.

- Highly imbalanced: `neutral` is 47% of the training split, so the majority-class baseline on the test split is 48.2%. Plain accuracy alone is not a useful indicator here.
- Utterance-level alignment in MELD is known to be imperfect ([declare-lab/MELD#30](https://github.com/declare-lab/MELD/issues/30)), which limits achievable accuracy.

## Model

- frontend: `s3prl` (`wavlm_base_plus`), frozen via `freeze_param`
- encoder: Transformer, 4 blocks, 128 dim, `input_layer: linear`
- decoder: linear head with mean pooling
